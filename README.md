# 🧠 GitHub Therapist

> Your GitHub needs therapy.

GitHub Therapist is an AI-powered developer profile analyzer that evaluates GitHub repositories and gives developers a brutally honest assessment of their project health, engineering practices, and recruiter readiness.

Instead of simply counting repositories, it looks at signals such as documentation, testing, project quality, and repository hygiene.

## ✨ What It Does

Enter a GitHub username and get:

- 🧠 Developer Health Score
- 💼 Recruiter Readiness Score
- 🟢 Strengths
- 🔴 Weaknesses
- 💊 Personalized Prescription
- 📂 Project-by-project health analysis
- 🤖 AI-generated feedback using Groq
- 🔥 Therapist, Roast and Recruiter modes

## 🧪 Example

```text
Developer Health: 58/100
Recruiter Readiness: 58/100

Diagnosis:
GitHub Needs Therapy

Strength:
Good documentation coverage

Weaknesses:
- Testing coverage is weak
- Several projects need stronger engineering signals

Prescription:
- Add meaningful tests
- Polish your strongest projects
- Focus on quality over quantity
